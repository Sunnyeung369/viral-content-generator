# 质量评估模板
# v4.0 - 自动评分和质量改进建议

## 评分维度

### 1. 钩子吸引力（Hook Score）
**评估标准**：
- 开头3句是否足够吸引人
- 是否有明确的钩子模式
- 是否激发好奇心

**评分标准**：
- 9-10分：钩子强力，立刻抓住注意
- 7-8分：钩子有效，有吸引力
- 5-6分：钩子一般，可以更好
- <5分：钩子薄弱，需要改进

**改进建议**：
- 使用反常识观点
- 提出引人思考的问题
- 讲述相关故事
- 制造悬念或好奇

### 2. 逻辑流畅度（Logic Score）
**评估标准**：
- 内容结构是否清晰
- 论证是否连贯
- 逻辑是否自洽

**评分标准**：
- 9-10分：逻辑严密，结构完美
- 7-8分：逻辑清晰，结构合理
- 5-6分：逻辑基本清晰，有瑕疵
- <5分：逻辑混乱，需要重构

**改进建议**：
- 检查段落间的过渡
- 确保每句话都有目的
- 避免跳跃式论证
- 添加必要的解释

### 3. 价值密度（Value Score）
**评估标准**：
- 信息密度是否足够
- 是否有可执行的建议
- 是否有独特的观点

**评分标准**：
- 9-10分：价值极高，干货满满
- 7-8分：价值较高，有干货
- 5-6分：价值一般，有水分
- <5分：价值低下，空洞无物

**改进建议**：
- 删除冗余表达
- 增加具体案例
- 提供可执行建议
- 加入数据支撑

### 4. 情感共鸣度（Emotion Score）
**评估标准**：
- 是否击中目标用户痛点
- 是否引发情感共鸣
- 是否有情绪起伏

**评分标准**：
- 9-10分：情感强烈，深度共鸣
- 7-8分：情感有效，引发共鸣
- 5-6分：情感一般，共鸣有限
- <5分：情感薄弱，无共鸣

**改进建议**：
- 加入具体的痛点描述
- 使用情感化表达
- 讲述有温度的故事
- 制造情绪高潮

### 5. 平台适配度（Platform Fit Score）
**评估标准**：
- 内容长度是否符合平台规范
- 表达方式是否匹配用户期待
- CTA是否符合平台特性

**评分标准**：
- 9-10分：完美适配，符合平台特性
- 7-8分：适配良好，基本符合
- 5-6分：适配一般，有改进空间
- <5分：适配不佳，需要调整

**改进建议**：
- 调整内容长度
- 优化表达方式
- 修改CTA形式
- 遵守平台规范

### 6. 成交有效性（Conversion Score）
**评估标准**：
- CTA是否清晰明确
- 转化路径是否合理
- 信任是否充分建立

**评分标准**：
- 9-10分：成交极有效，转化率高
- 7-8分：成交有效，有转化潜力
- 5-6分：成交一般，需要优化
- <5分：成交无效，需要重新设计

**改进建议**：
- 明确行动指引
- 优化转化路径
- 增加信任背书
- 制造紧迫感

## 综合评分

### 总分计算
```
总分 = (钩子 + 逻辑 + 价值 + 情感 + 平台 + 成交) / 6
```

### 质量等级
- **S级（9-10分）**：优秀内容，可直接发布
- **A级（8-9分）**：良好内容，小幅优化后发布
- **B级（7-8分）**：合格内容，需要优化
- **C级（6-7分）**：及格内容，需要较大改进
- **D级（<6分）**：不及格，需要重新创作

## 快速诊断

### 内容问题快速识别

| 问题表现 | 可能原因 | 改进建议 |
|---------|---------|---------|
| 开头无聊 | 钩子薄弱 | 加强开头吸引力 |
| 中途流失 | 逻辑不清晰 | 优化结构衔接 |
| 无互动 | 情感不足 | 增加情感共鸣点 |
| 无转化 | CTA不明确 | 强化行动召唤 |
| 平台表现差 | 适配不佳 | 调整平台特性 |

### 常见问题及解决方案

#### 问题1：开头不够吸引
**解决方案**：
- 删掉冗长的开场白
- 直奔主题或设置悬念
- 使用数据或金句开场

#### 问题2：内容太长太啰嗦
**解决方案**：
- 删除重复表达
- 合并相似段落
- 精简句式

#### 问题3：缺乏情感共鸣
**解决方案**：
- 加入具体场景描述
- 使用"你"而非"你们"
- 讲述相关故事

#### 问题4：CTA不清晰
**解决方案**：
- 明确告诉读者要做什么
- 使用行动动词
- 设置截止时间或名额限制

#### 问题5：数据和案例不足
**解决方案**：
- 添加具体数据
- 插入真实案例
- 提供可验证来源

## 改进优先级

### 高优先级（必须修改）
- 钩子吸引力 < 7分
- 逻辑流畅度 < 7分
- 成交有效性 < 7分

### 中优先级（建议修改）
- 价值密度 < 8分
- 情感共鸣度 < 8分
- 平台适配度 < 8分

### 低优先级（可选优化）
- 表达方式优化
- 排版美化
- 视觉增强
