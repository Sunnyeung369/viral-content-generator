# 平台适配模板
# v4.0 - 针对不同平台优化内容呈现

## 公众号

### 平台特征
- **内容深度**：支持长文，可深度展开
- **阅读场景**：安静阅读，注意力集中
- **用户期待**：深度、专业、有启发

### 内容策略
- **长度**：1500-3000字
- **结构**：完整清晰，分段明确
- **标题**：价值明确，适度吸引
- **排版**：舒适阅读，善用空行

### CTA策略
- 文末设置明确的行动指引
- 可放置二维码/链接
- 引导关注/加微信/咨询

### 适合风格
- Newsletter作者
- 深度评论
- 知识科普

## 视频号

### 平台特征
- **内容形式**：短视频为主（30-60秒）
- **视觉优先**：画面冲击力重要
- **用户期待**：快速获取价值，情绪共鸣

### 内容策略
- **长度**：30-60秒（或1-3分钟）
- **结构**：3秒抓人 → 主体干货 → 结尾CTA
- **表达**：口语化、有节奏、带情绪
- **视觉**：真人出镜，场景丰富

### CTA策略
- 口播引导（"点击下方链接"）
- 评论区置顶
- 引导私信/加微信

### 适合风格
- 商业毒舌
- 实用技巧
- 情感共鸣

## 小红书

### 平台特征
- **内容形式**：图文/短视频
- **用户群体**：年轻女性为主
- **用户期待**：精致、真实、种草

### 内容策略
- **长度**：图文500-1000字，视频15-45秒
- **结构**：标题吸引 → 场景描述 → 真实体验 → 推荐理由
- **视觉**：精致图片/真实生活
- **表达**：姐妹感、温暖、真诚

### CTA策略
- 自然种草，不硬推
- 评论引导（"姐妹们问我"）
- 引导私信/收藏

### 适合风格
- 生活美学
- 种草博主
- 美妆护肤

## 知乎

### 平台特征
- **内容形式**：长文回答
- **用户群体**：知识型用户
- **用户期待**：专业、有深度、可验证

### 内容策略

- **结构**：问题分析 → 多维解答 → 案例支撑 → 总结建议

- **排版**：清晰层次，善用小标题

### CTA策略
- 专业形象建立
- 引导私信咨询
- 机构号转化

### 适合风格
- 知识科普
- 专业分析
- 行业洞察

## 抖音

### 平台特征
- **内容形式**：短视频（15-60秒）
- **算法推荐**：流量去中心化
- **用户期待**：快节奏、强刺激、有反转

### 内容策略
- **长度**：15-60秒
- **结构**：3秒抓人 → 快节奏内容 → 反转/高潮 → CTA
- **表达**：节奏快、情绪饱满、有记忆点
- **视觉**：动态、冲击、创意

### CTA策略
- 强调紧迫感
- 引导点击购物车
- 评论区互动

### 适合风格
- 商业毒舌
- 实用技巧
- 娱乐搞笑

## B站

### 平台特征
- **内容形式**：中长视频（5-15分钟）
- **用户群体**：年轻、ACG爱好者
- **用户期待**：有趣、有深度、可互动

### 内容策略
- **长度**：5-15分钟
- **结构**：引入 → 展开 → 高潮 → 总结
- **表达**：有趣但不失专业，有梗
- **视觉**：动画、图表、弹幕互动

### CTA策略
- 视频中自然植入
- 引导三连（点赞投币收藏）
- 评论区置顶链接

### 适合风格
- 知识科普
- 深度分析
- 趣味讲解

## 跨平台复用策略

### 策略A：一次创作，多平台适配
```
核心内容（公众号长文）
    ↓
改编为视频号/抖音脚本
    ↓
提炼为小红书图文
    ↓
浓缩为微博观点
```

### 策略B：平台优先，分层创作
```
主平台（深度内容）
    ↓
精华提炼到次平台
    ↓
预告/引流到主平台
```

### 策略C：话题联动，矩阵覆盖
```
同一话题
    ↓
不同平台不同角度
    ↓
形成内容矩阵
```
