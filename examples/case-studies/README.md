# 匿名案例集

案例只记录工作流和验证方法，不虚构曝光或成交结果。贡献新案例时，请移除个人信息，并补充可复现命令。

## 案例模板

复制下面结构创建 `case-<name>.md`：

```markdown
# 案例：<一句话场景>
## 输入
<主题、平台、目标和风格>
## 生成命令
<可复现命令>
## 人工修改
<修改了哪些事实、语气或 CTA>
## 发布反馈
| 指标 | 数值 | 统计窗口 |
|---|---:|---|
| 曝光 | | |
| 互动 | | |
| 线索 | | |
## 下一轮只改一个变量
<要验证的假设>
```

反馈数据应来自真实发布记录；没有数据时请明确标注“未发布”。
