# Viral Content Generator v4.0 升级说明

> **从 v3.1.2 到 v4.0：从静态CLI工具到热点风格成交引擎**

---

## 版本对比

| 特性 | v3.1.2 | v4.0 |
|------|--------|------|
| **核心定位** | AI内容生成工具 | 热点风格成交引擎 |
| **风格系统** | 8种硬编码风格 | 155+外置风格基因卡 |

## 核心升级

### 1. 风格系统升级

**v3.1.2**：硬编码风格
```python
STYLES = {
    "理性科技": "...",
    "感性叙事": "...",
    # 8个风格写死在代码里
}
```

**v4.0**：外置风格基因库
```yaml
# data/styles/global_creators.yaml
styles:
  - id: tech_explainer_global
    label: "科技解释型创作者"
    style_dna:
      tone: "清晰、兴奋、未来感"
      sentence_rhythm: "短句开场，中句解释，结尾升维"
    hook_patterns:
      - "一个新技术正在改变..."
```

**升级价值**：
- ✅ 155+风格基因（从8种）
- ✅ 风格可组合（最多3种混合）
- ✅ 无需改代码即可添加风格

## 使用对比

### v3.1.2 使用方式

```bash
# 基础用法
python viral_article_cli.py "你的话题" --style 理性科技

# 指定AI模型
python viral_article_cli.py "你的话题" --model claude

# 指定平台
python viral_article_cli.py "你的话题" --platform 公众号
```

### v4.0 使用方式

```bash
# 基础用法（兼容v3）
python viral_content_cli.py "你的话题" --style-mix "global:tech_explainer"

# 完整用法
python viral_content_cli.py \
  --topic "你的话题" \
  --account data/accounts/ai_consultant.yaml \
  --offer data/offers/consulting.yaml \
  --style-mix "global:tech_explainer,china:business_savage" \
  --goal leads \
  --platform xiaohongshu \
  --output outputs/

# Python API
from viral_content import ViralContentPipeline, ConversionGoal, Platform

pipeline = ViralContentPipeline()
result = pipeline.run(
    topic="你的话题",
    account="data/accounts/ai_consultant.yaml",
    offer="data/offers/consulting.yaml",
    style_mix="global:tech_explainer",
    goal=ConversionGoal.LEADS,
    platform=Platform.XIAOHONGSHU
)
```

## 常见问题

### Q1: v3.1.2 还能用吗？

**A**: 可以。v4.0 保持最小向后兼容：
```bash
python viral_article_cli.py "话题" --style 理性科技
```

但建议使用新的 v4.0 CLI：
```bash
python viral_content_cli.py "话题" --style-mix "global:tech_explainer"
```

### Q2: 风格名称变了怎么办？

**A**: 使用新的风格ID系统：
```bash
# 旧: --style 理性科技
# 新: --style-mix "global:tech_explainer"
```

查看所有风格：
```python
from viral_content import StyleMixer
mixer = StyleMixer()
print(mixer.list_styles())
```

### Q3: 我的自定义配置在哪？

**A**: 所有配置外置在 `data/` 目录：
- 账号配置：`data/accounts/`
- 产品配置：`data/offers/`
- 风格配置：`data/styles/`

### Q4: 如何添加新风格？

**A**: 编辑风格YAML文件，添加新风格卡：
```yaml
# data/styles/global_creators.yaml
styles:
  - id: my_custom_style
    label: "我的风格"
    style_dna:
      tone: "你的语气"
    hook_patterns:
      - "你的钩子"
```
