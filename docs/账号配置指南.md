# 账号配置指南

> **v4.0 账号指纹系统使用指南**

---

## 什么是账号指纹？

账号指纹是你账号的"DNA"，它定义了：
- 你是谁（身份定位）
- 你服务谁（目标用户）
- 你解决什么问题（用户痛点）
- 你的权威在哪里（权威资产）
- 你想达成什么（商业目标）

---

## 配置结构

### 完整模板

```yaml
account:
  # 基本信息
  name: "账号名称"
  identity: "一句话定位"

  # 目标用户
  target_audience:
    - "目标用户1"
    - "目标用户2"

  # 用户痛点
  pain_points:
    - "痛点1"
    - "痛点2"

  # 权威资产
  authority_assets:
    - "资产1"
    - "资产2"

  # 商业目标
  business_goal:
    primary: "主要目标"
    secondary: "次要目标"

  # 产品阶梯
  offer_ladder:
    free: "免费诱饵"
    low_ticket: "低价产品"
    mid_ticket: "中价产品"
    high_ticket: "高价服务"

  # 语气限制
  tone_constraints:
    - "限制1"
    - "限制2"

  # 内容限制
  content_constraints:
    - "限制1"
    - "限制2"

  # 平台偏好
  platform_preferences:
    primary: ["主平台1", "主平台2"]
    secondary: ["次平台1"]
```

---

## 字段详解

### 1. 基本信息

#### name (账号名称)

```yaml
name: "AI效率顾问"
```

**命名建议**：
- ✅ 简洁明了（2-6个字）
- ✅ 体现定位
- ✅ 容易记忆

**示例**：
- ✅ "AI效率顾问"
- ✅ "增长黑客Sarah"
- ✅ "电商老司机"

#### identity (身份定位)

```yaml
identity: "专注AI工具落地的实战顾问"
```

**定位公式**：
```
专注[领域]的[角色]类型
```

**示例**：
- ✅ "专注AI工具落地的实战顾问"
- ✅ "帮助DTC品牌做增长的运营专家"
- ✅ "中小企业数字化转型咨询师"

### 2. 目标用户 (target_audience)

```yaml
target_audience:
  - "职场人士（想用AI提升效率）"
  - "内容创作者（用AI辅助创作）"
  - "自由职业者（用AI放大产出）"
```

**用户画像要素**：
- 身份/职业
- 核心需求
- 使用场景

**示例**：
```yaml
# 好的用户描述
target_audience:
  - "中小品牌主理人（0-1阶段）"
  - "电商创业者（日销1万以下）"
  - "传统企业转型电商负责人"

# 不好的用户描述
target_audience:
  - "所有人"  # ❌ 太宽泛
  - "用户"    # ❌ 没有信息
```

### 3. 用户痛点 (pain_points)

```yaml
pain_points:
  - "知道AI有用，但不知道怎么用"
  - "工具太多，不知道从哪开始"
  - "学了一堆工具，还是不会工作流设计"
```

**痛点设计原则**：
- ✅ 具体场景化
- ✅ 情感化表达
- ✅ 展示理解

**痛点类型**：
1. **认知痛点** - "不知道怎么用"
2. **效率痛点** - "太慢、太复杂"
3. **成本痛点** - "太贵、不划算"
4. **风险痛点** - "担心失败、害怕踩坑"

### 4. 权威资产 (authority_assets)

```yaml
authority_assets:
  - "3年AI实战经验"
  - "服务过50+企业客户"
  - "累计学员2000+"
  - "运营着2万人的AI社群"
```

**权威类型**：

| 类型 | 示例 | 作用 |
|------|------|------|
| 经验类 | "5年行业经验" | 展示资历 |
| 数据类 | "服务50+客户" | 量化证明 |
| 案例类 | "某品牌从0到1案例" | 成功背书 |
| 认证类 | "XX认证专家" | 第三方认可 |
| 社群类 | "运营2万人社群" | 影响力证明 |

### 5. 商业目标 (business_goal)

```yaml
business_goal:
  primary: "获取咨询线索"  # 主要目标
  secondary: "推广付费课程" # 次要目标
```

**目标类型**：

| 目标 | 适用场景 |
|------|----------|
| 获取咨询线索 | 高客单价服务 |
| 获取付费学员 | 标准化课程 |
| 直接成交 | 标准化产品 |
| 品牌曝光 | 新账号/新品牌 |
| 私域引流 | 社群运营 |

### 6. 产品阶梯 (offer_ladder)

```yaml
offer_ladder:
  free: "免费工具清单"
  low_ticket: "¥199 AI速成课"
  mid_ticket: "¥2999 实战营"
  high_ticket: "¥15000 一对一咨询"
```

**阶梯设计原则**：

1. **免费诱饵** - 降低门槛
   - 工具清单
   - 电子书
   - 视频教程

2. **低价产品** - 建立信任
   - ¥99-299 的小课
   - 一次性服务
   - 工具包

3. **中价产品** - 主要收入
   - ¥999-4999 的课程
   - 小型训练营
   - 咨询套餐

4. **高价服务** - 高利润
   - ¥10000+ 的咨询
   - 年度服务
   - 企业培训

### 7. 语气限制 (tone_constraints)

```yaml
tone_constraints:
  - "实战派，说人话"
  - "有干货不枯燥"
  - "能落地执行"
```

**语气类型**：

- 专业但不失亲和
- 幽默但不轻浮
- 犀利但有价值
- 温暖但有边界

### 8. 内容限制 (content_constraints)

```yaml
content_constraints:
  - "不做任何项目的财务建议"
  - "不推荐具体标的"
  - "仅做市场分析和方法论分享"
```

**限制类型**：

- 合规限制（如金融、医疗）
- 职业边界（如不做法律建议）
- 内容边界（如不讨论政治）
- 平台规则（如不违规引流）

## 使用指南

### 创建配置文件

```bash
# 1. 复制模板
cp data/accounts/default_account.yaml data/accounts/my_account.yaml

# 2. 编辑配置
vim data/accounts/my_account.yaml

# 3. 验证配置
python -c "from viral_content import AccountFingerprintLoader; print(AccountFingerprintLoader().load_account('data/accounts/my_account.yaml'))"
```

### 在代码中使用

```python
from viral_content import (
    PipelineBuilder,
    ConversionGoal,
    Platform
)

result = (PipelineBuilder()
    .with_account("data/accounts/my_account.yaml")  # 使用你的配置
    .with_offer("data/offers/my_offer.yaml")
    .with_styles("tech_explainer_global")
    .with_goal(ConversionGoal.LEADS)
    .with_platform(Platform.XIAOHONGSHU)
    .generate("你的话题"))
```

## 常见问题

### Q1: 账号配置必需吗？

**A**: 不是必需，但强烈推荐。没有账号配置：
- ✅ 仍然可以生成内容
- ❌ 内容缺乏一致性
- ❌ 无法精准定位用户
- ❌ 转化效果会打折扣

### Q2: 可以有多个账号配置吗？

**A**: 可以。根据不同业务线创建不同配置：
```bash
data/accounts/
├── ai_consultant.yaml      # AI咨询业务
├── ecommerce_service.yaml  # 电商服务
└── personal_brand.yaml     # 个人品牌
```

### Q3: 配置文件出错怎么办？

**A**: 系统会自动使用默认值。建议：
1. 检查YAML语法
2. 使用配置验证工具
3. 参考示例配置

## 总结

**账号配置的核心价值**：

1. **一致性** - 所有内容保持统一调性
2. **精准性** - 精准定位目标用户
3. **专业性** - 展示权威和信任
4. **转化性** - 每篇内容都有转化目标

**配置三要素**：
1. 你是谁（identity）
2. 服务谁（target_audience）
3. 达成什么（business_goal）

**开始使用**：
1. 复制模板
2. 填写你的信息
3. 测试生成
4. 持续优化
